빈칸에 들어갈 그림은?

어떤 게임인가요?

3×3 칸에 놓인 그림들은 모양·색·개수·크기·방향 같은 규칙을 따라요. 가로줄과 세로줄을 비교해 규칙을 찾고, 빈칸에 들어갈 그림을 고르면 돼요. 지능검사에 쓰이는 행렬 추리(레이븐 매트릭스) 방식이고, 중간중간 수열 문제도 나와요.

잘 푸는 요령

한 번에 한 가지 속성만 보세요. 개수 → 모양 → 색 → 채우기 → 크기 → 방향 순서로 하나씩 규칙을 확인하면 대부분 풀려요. 무한 도전에서 틀리면 규칙 해설이 나오니 반복하면 실력이 늘어요.
