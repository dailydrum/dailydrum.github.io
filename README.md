# DailyDrum

연습의 첫 박부터, 무대의 마지막 박까지.

DailyDrum 메트로놈의 공식 홍보 홈페이지입니다.

- 홈페이지: https://dailydrum.github.io/
- App Store: https://apps.apple.com/app/id6808595998
- Instagram: https://www.instagram.com/daily_drum_/

Tempo · List · Practice · Live 기능을 소개합니다.
이 저장소에는 홍보용 정적 페이지, 이미지, 사용 설명서, 업데이트 안내와 app-ads.txt를 포함합니다.
모바일 앱 소스, 설치 파일, 음원, 계정 정보 및 서명키는 포함하지 않습니다.

GitHub Pages에서 main 브랜치의 루트 폴더를 게시합니다.
app-ads.txt 게시와 AdMob의 최종 인증은 별개입니다.
