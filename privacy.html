개인정보처리방침

개정일: 2026년 9월 9일

이 방침은 DailyDrum이 제공하는 TEMPO - 데일리 드럼(스토어 이름: Tempo - 데일리드럼 메트로놈, 이하 “앱”)에 적용됩니다. 앱은 계정 없이 사용하는 메트로놈입니다.

앱에서 처리하는 정보

템포, 강세, 음표 분할, 사운드, 볼륨, 연주목록과 연습 설정은 기기 안의 앱 저장 공간에 보관됩니다. 개발자는 이 정보를 서버로 수집하지 않습니다. 앱에는 광고, 분석 SDK, 광고 목적의 추적 또는 인앱 결제가 없습니다.

앱은 계정, 이름, 이메일, 연락처 또는 위치를 입력받지 않으며 카메라나 마이크로 녹음하지 않습니다. 개인정보를 판매하지 않습니다.

네트워크와 외부 서비스

버전 2.3.4 및 2.3.5의 메트로놈과 연주목록 기능은 기기 안에서 작동합니다. 버전 2.3.6부터는 앱 실행 시 GitHub Pages에서 업데이트 정책 파일을 HTTPS로 확인합니다. 요청에 로그인 정보, 광고 식별자, 기기 고유 ID, 연주목록, 음원, 설정 또는 현재 앱 버전을 별도 데이터로 보내지 않습니다. 버전 비교는 기기에서 수행하며, 연결에 실패해도 메트로놈을 사용할 수 있습니다.

GitHub Pages에 접속하면 호스팅 제공자 GitHub가 보안 목적으로 IP 주소를 기록·저장합니다. 이 웹사이트를 방문할 때도 해당됩니다. 자세한 내용은 GitHub Pages 안내와 GitHub 개인정보 처리방침을 확인해 주세요.

문의, 보관 및 삭제

지원 이메일로 직접 문의하면 회신과 문제 해결을 위해 이메일 주소와 문의 내용을 처리합니다. 문의 정보는 지원 처리에 필요한 동안 보관하며, 삭제를 요청하려면 아래 이메일로 연락해 주세요. 법령상 보관이 필요한 경우 해당 의무가 적용될 수 있습니다.

기기에 저장한 연주목록과 설정은 앱에서 관리할 수 있습니다. 앱을 제거하거나 운영체제의 앱 데이터 삭제 기능을 이용하면 운영체제의 백업·복원 정책에 따라 해당 데이터가 삭제됩니다. GitHub가 처리하는 접속 정보의 보관·삭제는 GitHub 개인정보 처리방침에 따릅니다.

Privacy Policy

Updated September 9, 2026

This policy applies to TEMPO - Daily Drum, also listed as Tempo - 데일리드럼 메트로놈, provided by DailyDrum (the “App”). The App is a metronome that requires no account.

Information handled by the App

Tempo, accents, subdivisions, sounds, volume, setlists and practice settings are stored on your device. The developer does not upload them to a server. The App contains no advertising, analytics SDK, advertising tracking or in-app purchases. It does not ask you to provide an account, name, email, contacts or location, and does not record through your camera or microphone. Personal information is not sold.

Network connections and service providers

In versions 2.3.4 and 2.3.5, the metronome and setlist features operate on-device. Starting with version 2.3.6, the App requests an update-policy file from GitHub Pages over HTTPS at launch. It does not send login credentials, advertising identifiers, unique device IDs, setlists, audio, settings or the installed app version as additional request data. Version comparisons happen on-device. A failed network request does not prevent metronome use.

GitHub logs and stores visitor IP addresses for security when GitHub Pages is accessed, including visits to this website. See GitHub Pages documentation and GitHub’s Privacy Statement.

Support, retention and deletion

If you email support, your email address and message are used to respond and resolve your request. Support information is retained as needed to provide support, subject to applicable legal retention obligations. Contact us to request deletion.

Local setlists and preferences can be managed in the App. Uninstalling the App or clearing its data removes local data subject to operating-system backup and restoration behavior. GitHub’s retention and deletion of connection information are governed by its privacy statement.
