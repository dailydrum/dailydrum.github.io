# TEMPO 2.4.0

2.4 업데이트 안내입니다. 스토어 배포 전인 기능이 포함되어 있습니다.

- 드럼 비트: 킥·스네어·하이햇, 16스텝 편집, 8비트/16비트 프리셋, 현재 패턴 저장.
- 간결한 조작: 큰 재생 버튼, 통일된 음표, 촘촘한 곡 목록, List의 TAP.
- 영어 카운트: 한 박 미리듣기, 보이스 길이 조절, AND 잔여음 정리 및 음량 조정.
- 기존 기능도 새 설명서에 정리: 곡별 예비박, 목록 파일 공유, Live 즉석 설정, 오토메이터·트래커, 비트 라이트.
- 추가 테스트 빌드 40: 재생 중 박자표·분할 변경 시 카운트가 앞당겨질 수 있던 문제와 연습 예비박 연결을 수정.

[한국어 사용 설명서](../TEMPO-2.4.0-guide-ko.pdf)

설명서는 빌드 40 기준이며, 설치된 스토어 버전과 기능이 다를 수 있습니다.
Android 링크는 초대된 계정용 내부 테스트입니다.
