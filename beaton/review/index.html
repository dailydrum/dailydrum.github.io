Purpose of the permission

BEAT:ON is a music practice player. The user explicitly starts a local track. The FOREGROUND_SERVICE_MEDIA_PLAYBACK service keeps that user-requested playback active when the user leaves the app, with a visible media notification and a pause control. Interrupting playback when switching apps would interrupt the user's music practice.

Demonstrated workflow

  1. Start the local synthetic practice track using the Play button.
  2. Leave BEAT:ON for the Android home screen.
  3. Open the notification shade and show the BEAT:ON media playback notification.
  4. Return to the player and observe the advanced playback position.
  5. Pause from the notification and confirm playback is paused in the app.
