개인정보처리방침

적용일: 2026년 9월 8일 · BEAT:ON iOS 앱 및 공식 홍보 사이트

BEAT:ON은 곡 분석과 템포 처리를 기기에서 실행합니다. 이 방침은 DailyDrum이 제공하는 BEAT:ON 앱과 이 안내 사이트에 적용됩니다.

1. 기기에 보관하는 음악

가져온 음원, 곡 이름, 분석 결과, 재생목록과 연습 설정은 현재 기기에 저장됩니다. 음원 분석과 템포 처리는 기기에서 수행되며, 개발자 분석 서버로 음원을 전송하지 않습니다.

2. iOS 앱의 수집과 추적

iOS 앱에는 회원가입, 광고, 추적 도구, 사용 통계 수집 기능이 없습니다. 개발자가 앱을 통해 음원, 연락처, 위치, 광고 식별자 등 개인정보를 수집하거나 판매하지 않습니다.

3. 직접 접속하는 외부 서비스

음원 링크 가져오기를 선택하면 사용자가 입력한 주소의 서버로 직접 요청합니다. 해당 서비스는 IP 주소 등의 접속 정보를 처리할 수 있으며, 그 서비스의 개인정보처리방침이 적용됩니다. 외부 고객지원 페이지 역시 사용자가 링크를 열 때 연결됩니다.

4. 삭제와 백업

앱 라이브러리에서 곡을 삭제하면 앱에 저장된 해당 음원과 분석 결과가 삭제됩니다. 앱을 삭제하면 앱의 로컬 자료도 삭제됩니다. 원본 파일과 사용자가 직접 내보낸 파일은 별도로 삭제해야 합니다.

iOS 백업 여부는 사용자의 Apple 계정과 기기 백업 설정에 따릅니다. Apple이 제공하는 백업 등 시스템 서비스에는 Apple의 정책이 적용됩니다. BEAT:ON은 별도의 계정 기반 곡 동기화를 제공하지 않습니다.

5. 공식 홍보 사이트

이 사이트에는 광고, 방문 분석 도구, 가입 양식, 음원 업로드 기능을 넣지 않았습니다. 호스팅 제공자인 GitHub는 사이트 보안을 위해 방문자의 IP 주소를 기록·보관할 수 있습니다. 자세한 내용은 GitHub Pages의 데이터 수집 안내와 GitHub 개인정보처리방침에서 확인할 수 있습니다.

6. 고객지원 문의

문의는 DailyDrum GitHub 공개 문의에서 접수합니다. 사용자가 직접 작성한 문의 내용과 GitHub 프로필 정보는 문제 확인과 답변을 위해 사용되며, GitHub의 공개 게시물로 표시됩니다. 게시물의 수정·삭제는 GitHub가 제공하는 기능을 이용하거나 해당 문의에서 요청할 수 있습니다.

문의 과정에 필요한 범위를 넘어 개인정보를 별도로 수집하지 않습니다. 개인 연락처나 비공개 음악 파일이 포함되지 않도록 공개 범위를 확인해 주세요.

7. 방침의 변경

앱의 데이터 처리 방식이 변경되면 이 페이지의 적용일과 내용을 갱신합니다. 개인정보에 관한 질문은 위 고객지원 채널로 BEAT:ON 개인정보 문의임을 알려주세요.
